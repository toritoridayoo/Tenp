---
name: Giveaway claim handling
description: Product rule for how Giveaway prize claims should be processed in the Discord bot.
---

Giveaway prize claims must create an ordinary support ticket for staff to review and handle manually. Do not automatically grant or deliver Giveaway rewards.

**Why:** the user explicitly said the Giveaway flow does not need automatic claiming.

**How to apply:** preserve manual staff handling in future Giveaway ticket or reward changes unless the user asks to automate it.
